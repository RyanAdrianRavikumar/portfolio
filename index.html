Food Ordering App

Together with my team, I developed a food ordering application using a microservices architecture. We utilized several technologies, including:

  • Spring Boot – To develop the backend microservices
  • REST – To expose backend APIs
  • React – To build the frontend interface
  • Axios – To handle API requests on the frontend
  • MySQL – To manage database storage

The microservices we implemented include:

  • User Service – Handles user registration, authentication, and profile management
  • Restaurant Service – Manages and displays dynamic restaurant details
  • Menu Service – Retrieves and displays menu information dynamically
  • Discount Service – Validates discount codes
  • Order Service – Processes user orders and calculates payments
  • Review Service – Manages user reviews and ratings
  • Email Notification Service – Sends order confirmation emails
